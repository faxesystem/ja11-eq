Import EQ into USER1

Paste text or pick a file. Supported:

  • graph.hangout.audio / squig.link: the file from “Export Parametric EQ” or the “Share your PEQ” link
  • AutoEQ (“Equalizer APO” format) and REW filter exports

The JA11 has 5 bands (±12 dB); longer profiles are cut down to their 5 strongest filters. Tip: Cmd/Ctrl+V anywhere on the page or dropping a .txt onto the graph works too.

Reset

Neutral: sets USER1 flat (1000 / 2000 / 5000 / 8000 / 10000 Hz, all 0 dB, Q 0.7), then makes the dongle start with EQ off. Safe, but not necessarily the factory state of USER1.

Reset command (experimental): sends FiiO's “reset EQ” command (0x1B) and reads USER1 back. Its effect on the JA11 is undocumented – in tests it changed nothing. Only EQ data is affected, never the firmware.

Your current USER1 is backed up in the browser first (Import EQ → “Restore backup”).

Good to know

  • Only USER1 is editable. Vocal, Classic and Bass are fixed factory presets – view them or copy them to USER1.
  • Clicking a preset switches it right away, but only until the dongle is unplugged. Save decides what the dongle starts with – on any device, phones included.
  • With Off selected, the button reads “Start with EQ off”.
  • The green dot marks what is currently running on the dongle.
  • Pre-gain: the JA11 attenuates USER1 internally by 12 dB, so +12 dB (default) matches the level of the factory presets. “Auto” subtracts the largest boost – clip-safe, but quieter.
  • The curve shows the requested filters (RBJ biquads at 48 kHz); the firmware renders shelves slightly steeper.
